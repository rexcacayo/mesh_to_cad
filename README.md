# Mesh to CAD

Complemento de Blender (4.2 a 5.x) que convierte un STL o un escaneo en un **sólido limpio**: reconoce
caras planas, agujeros y ejes (con sus diámetros), endereza la pieza a los ejes y la guarda en **STEP**
para editarla en Fusion 360, FreeCAD u Onshape. Todo en modo Objeto.

Instalar: Editar → Preferencias → Complementos → Instalar desde disco → `version_1.0.0/dist/mesh_to_cad-1.0.0.zip`.
Vista 3D → **N** → pestaña **Mesh to CAD**. Guía: `version_1.0.0/mesh_to_cad/LEEME.md`.
